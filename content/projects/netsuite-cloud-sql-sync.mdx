## The problem

Business data lived inside NetSuite, and getting it into a form analysts could query meant manual exports and spreadsheet work every reporting cycle.

## What I built

- **Extraction:** NetSuite RESTlet APIs, authenticated with OAuth 1.0 request signing.
- **Load:** Python jobs that write into MySQL on Google Cloud SQL.
- **Scheduling:** Google Cloud Scheduler runs the sync daily, so no one has to remember to.
- **Modeling:** staging tables designed and optimized for faster ERP analysis and as a clean base for AI/BI applications.

Done during my Software Engineering Intern role at Namo Cloud Solutions (Denver, summer 2025).
